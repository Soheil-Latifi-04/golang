# go-HRMS

A minimal HR Management System (HRMS) REST API written in Go. It exposes CRUD
endpoints for managing employee records, backed by MongoDB.

## Purpose

This project is a small backend service for storing and managing basic
employee data — name, salary, and age. It's built as a learning/reference
project for wiring up a Go web server to a MongoDB database with full
Create, Read, Update, and Delete (CRUD) operations, and is a good starting
point for a larger HR or employee-management system.

## Tech stack

| Tool | Why it's used |
|---|---|
| **Go** (1.26) | Fast, statically typed, compiles to a single binary — a good fit for small, efficient backend services. |
| **[Fiber v3](https://github.com/gofiber/fiber)** | An Express.js-style web framework for Go, built on `fasthttp`. Chosen for its speed and simple, minimal-boilerplate API for defining routes and handlers. |
| **[MongoDB](https://www.mongodb.com/)** | A document database that stores JSON-like records. A natural fit here since the `Employee` struct maps directly to a document — no schema migrations needed for a simple, evolving data model. |
| **[MongoDB Go Driver](https://github.com/mongodb/mongo-go-driver)** | The official Go client for MongoDB, used to connect, query, insert, update, and delete employee documents. |
| **Fiber's `logger` middleware** | Logs each incoming request (method, path, status, latency) to stdout for basic visibility during development. |

## API Endpoints

| Method | Route | Description |
|---|---|---|
| GET | `/employee` | List all employees |
| GET | `/employee/{id}` | Get a single employee by ID |
| POST | `/employee` | Create a new employee |
| PUT | `/employee/{id}` | Update an existing employee |
| DELETE | `/employee/{id}` | Delete an employee |

### Employee JSON shape

```json
{
  "id": "665f1c2e8b3a1e2f3c4d5e6f",
  "name": "Jane Doe",
  "salary": 75000,
  "age": 32
}
```

`id` is generated by MongoDB and returned in responses — you don't need to
send it when creating or updating an employee.

## Prerequisites

- [Go](https://go.dev/dl/) 1.26 or later
- [MongoDB](https://www.mongodb.com/try/download/community) running locally, or a connection string to a hosted instance (e.g. MongoDB Atlas)

## How to run

1. **Clone the repo and move into the project folder**

   ```bash
   git clone https://github.com/Soheil-Latifi-04/golang.git
   cd golang/go-HRMS
   ```

2. **Start MongoDB** (skip this if you're using a hosted/remote database)

   ```bash
   mongod
   ```

3. **(Optional) Set the database connection string**

   By default the app connects to `mongodb://localhost:27017`. To point it
   at a different database (e.g. MongoDB Atlas), set the `MONGO_URI`
   environment variable before running it:

   ```bash
   export MONGO_URI="mongodb+srv://<user>:<password>@<cluster-url>/"
   ```

4. **Install dependencies**

   ```bash
   go mod tidy
   ```

5. **Run the server**

   ```bash
   go run main.go
   ```

   You should see:

   ```
   Connected to MongoDB  fiber-hrms
   ```

   The API is now running at `http://localhost:3000`.

6. **Try it out**

   ```bash
   # Create an employee
   curl -X POST http://localhost:3000/employee \
     -H "Content-Type: application/json" \
     -d '{"name": "Jane Doe", "salary": 75000, "age": 32}'

   # List all employees
   curl http://localhost:3000/employee

   # Get one employee (replace <id> with the id returned above)
   curl http://localhost:3000/employee/<id>

   # Update an employee
   curl -X PUT http://localhost:3000/employee/<id> \
     -H "Content-Type: application/json" \
     -d '{"name": "Jane Doe", "salary": 80000, "age": 33}'

   # Delete an employee
   curl -X DELETE http://localhost:3000/employee/<id>
   ```
